# KOREA MAP — 한국 주식시장 히트맵 (완전 자동 갱신)

FINVIZ MAP 형식을 한국 시장에 맞춘 트리맵 히트맵입니다.
상승 **RED** / 하락 **BLUE**, 셀 크기는 시가총액 비례, 섹터별로 묶어 표시합니다.

**설정을 한 번 끝내면 이후 사람 손이 필요 없습니다.**
매 영업일 16:30(KST)에 GitHub이 알아서 KRX 데이터를 받아 사이트를 다시 배포합니다.

---

## 1. 5분 설정 (한 번만)

### ① GitHub 계정 만들기
[github.com](https://github.com) 에서 무료 계정을 만듭니다. (이미 있으면 건너뜁니다)

### ② 저장소 만들기
- 오른쪽 위 **+** → **New repository**
- Repository name: `korea-map`
- **Public** 선택 (무료 GitHub Pages는 Public에서만 동작합니다)
- **Create repository** 클릭

### ③ 파일 올리기
- 방금 만든 저장소 화면에서 **Add file** → **Upload files**
- 이 폴더의 **모든 파일과 폴더를 통째로** 끌어다 놓습니다
  (`.github` 폴더가 반드시 포함되어야 합니다 — 이 안에 자동 갱신 설정이 들어 있습니다)
- 아래 **Commit changes** 클릭

> `.github` 폴더가 안 보이면 숨김 폴더가 가려진 것입니다.
> Windows: 탐색기 → 보기 → 숨긴 항목 체크 / Mac: `Cmd+Shift+.`

### ④ GitHub Pages 켜기
- 저장소 상단 **Settings** → 왼쪽 **Pages**
- **Source** 를 **GitHub Actions** 로 선택

### ⑤ 자동 갱신 권한 켜기
- **Settings** → 왼쪽 **Actions** → **General**
- 맨 아래 **Workflow permissions** 에서 **Read and write permissions** 선택 → **Save**

### ⑥ 첫 실행
- 저장소 상단 **Actions** → 왼쪽 **Update KOREA MAP** → 오른쪽 **Run workflow** → **Run workflow**
- 2~3분 후 초록색 체크가 뜨면 완료. 주소는 이렇게 생깁니다:

```
https://<GitHub아이디>.github.io/korea-map/
```

이 주소를 누구에게든 보내면 됩니다. 로그인 없이 바로 열립니다.

## 2. 이후 동작

| 시각 (KST) | 동작 |
|---|---|
| 평일 16:30 | KRX 데이터 조회 → 사이트 재배포 |
| 평일 18:30 | 16:30 실행이 실패했을 경우를 대비한 재시도 |
| 주말·공휴일 | 데이터가 바뀌지 않으므로 그대로 유지 |

**실패해도 사이트는 절대 깨지지 않습니다.**
- 일부 기간 조회만 실패 → 그 기간은 직전 값을 유지하고 나머지는 갱신
- 핵심 데이터 조회 실패 → 아무것도 배포하지 않고 이전 사이트를 그대로 유지
- `verify_data.py` 가 종목수·시가총액·등락률 이상치를 검사해, 이상하면 배포를 막습니다

갱신 상태는 사이트 상단 파란 띠에 **기준일 · 갱신 시각**으로 항상 표시됩니다.

## 3. 기능

- **MAP 필터** KOSPI(시총 상위 200) · KOSDAQ(상위 150) · ETF(주요 54종)
- **PERFORMANCE** 1D · 1W · 1M · 3M · 6M · 1Y · 3Y · 5Y · 10Y
- **셀 크기 3단계** 시총가중 → **시총√가중** → 동일가중
  국내는 삼성전자·SK하이닉스가 시총 절반을 차지해 나머지가 안 보이므로,
  √가중을 누르면 200종목 이름이 거의 다 읽힙니다
- **섹터 확대** 섹터 이름 띠 클릭 → 해당 섹터만 확대, 다시 클릭 → 복귀
- **툴팁** 업종·현재가·시가총액 + 9개 기간 수익률 동시 표시
- **검색** 종목명·종목코드 입력 시 해당 셀만 강조
- **셀 클릭** 네이버금융 해당 종목 시세 페이지로 이동
- 다크/라이트 테마, 모바일 대응

## 5. 사내망에서 수동으로 돌릴 때

외부 인터넷이 막힌 PC에서는 KRX 엑셀 파일을 직접 읽는 방식도 됩니다.

1. KRX 정보데이터시스템(data.krx.co.kr)
   - **[통계] → [기본통계] → [주식] → [종목시세] → [전종목 시세]** → 저장 → `price.csv`
   - **[통계] → [기본통계] → [주식] → [순위정보] → [전종목 등락률]** → 조회기간을
     1D/1W/1M/3M/6M/1Y/3Y/5Y/10Y 로 각각 지정해 저장 → `chg_1D.csv` … `chg_10Y.csv`
2. 위 파일을 `krx` 폴더에 모으고

```bash
pip install pandas openpyxl
python update_korea_map.py --backend excel --dir ./krx --out .
```

`korea_map.html` 이 새로 만들어집니다. 외부 통신이 전혀 없는 단일 파일이라 사내 PC에서도 그대로 열립니다.

## 6. 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` / `korea_map.html` | 완성된 페이지 (같은 내용, 단일 파일) |

| `.github/workflows/update-map.yml` | 자동 갱신·배포 설정 |

## 7. 알아둘 점

- **첫 실행 전 데이터** — 지금 들어 있는 데이터는 시가총액·현재가·1일 등락률만 실제(2026-09-03 기준)이고
  나머지 기간과 ETF 수치는 샘플입니다. ⑥ 첫 실행을 한 번 돌리면 9개 기간 전부 실제 데이터로 바뀌고
  상단 안내 띠도 붉은 경고에서 파란 KRX 표시로 바뀝니다.
- **GitHub Actions 무료 한도** — Public 저장소는 무제한입니다. 이 작업은 1회 2~3분이므로 여유롭습니다.
- **60일 규칙** — GitHub은 60일간 저장소 활동이 없으면 예약 실행을 잠시 멈춥니다.
  이 워크플로는 매일 `data.json` 을 커밋하므로 활동이 계속 기록되어 해당하지 않습니다.
- **KRX 조회 안정성** — 해외 서버(GitHub)에서 KRX를 조회하므로 드물게 차단·지연이 있을 수 있습니다.
  그래서 호출당 3회 재시도, 하루 2회 실행, 실패 시 이전 데이터 유지를 모두 넣어 두었습니다.
