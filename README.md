# KOREA MAP — 한국 주식시장 히트맵

FINVIZ MAP 형식을 한국 시장에 맞춘 트리맵 히트맵입니다.
**상승 초록 / 하락 빨강**, 셀 크기는 시가총액 기준, 섹터별로 묶어 표시합니다.

**보기:** https://bluelagoon1222.github.io/Finviz-Korea/

로그인 없이 누구나 열 수 있습니다. 평일 장중 30분마다 자동 갱신됩니다.

---

## 1. 무엇을 보여주는가

- **대상** KOSPI 시총 상위 200 · KOSDAQ 상위 150 · 주요 ETF 54종, 약 404종목
- **기간** 1D · 1W · 1M · 3M · 6M · 1Y · 3Y · 5Y · 10Y 수익률
- **셀 크기 3단계** 시총가중 → **시총√가중(기본)** → 동일가중

국내 시장은 삼성전자·SK하이닉스가 시총에서 큰 비중을 차지해 단순 시총 가중으로는
나머지 종목이 보이지 않습니다. 그래서 **√가중을 기본값**으로 두었습니다.
이 상태에서 200종목 이름이 대부분 읽힙니다.

---

## 2. 사용법

| 동작 | 결과 |
|---|---|
| 상단 KOSPI / KOSDAQ / ETF | 지도 전환 |
| PERFORMANCE 버튼 | 기간 변경 (1D ~ 10Y) |
| 셀 크기 버튼 | 시총가중 / √가중 / 동일가중 전환 |
| 섹터 이름 띠 클릭 | 해당 섹터만 확대, 다시 클릭하면 복귀 |
| 셀에 마우스 올리기 | 업종 · 현재가 · 시가총액 + 9개 기간 수익률 |
| 검색창에 종목명·코드 입력 | 해당 셀만 강조 |
| 셀 클릭 | 네이버금융 종목 시세 페이지로 이동 |

다크·라이트 테마를 지원하고 모바일에서도 열립니다.

---

## 3. 자동 갱신

GitHub Actions가 평일에 자동으로 데이터를 받아 사이트를 다시 배포합니다.
사람이 손댈 일은 없습니다.

| 시각 (KST) | 동작 |
|---|---|
| 09:07 ~ 15:37, 30분 간격 (14회) | 장중 데이터 갱신 및 재배포 |
| 15:47 (1회) | 마감 확정치 갱신, 기준 데이터 저장 |
| 주말 · 공휴일 | 실행하지 않음 |

정각·30분이 아니라 7분·37분에 도는 것은 의도된 설정입니다.
GitHub 예약 실행은 정각에 부하가 몰려 지연·누락이 잦기 때문입니다.

갱신 상태는 사이트 상단 띠에 **기준일 · 갱신 시각**으로 항상 표시됩니다.

### 실패해도 사이트는 깨지지 않습니다

- 시세 수집 실패 → 저장된 직전 데이터로 사이트를 그대로 유지
- `verify_data.py` 가 종목 수 · 시가총액 · 등락률 이상치를 검사해 이상하면 배포를 막음
- 한 회차가 누락되어도 30분 뒤 다음 회차가 정상 실행

---

## 4. 데이터

시세는 **yfinance**를 통해 수집합니다 (`fetch_yahoo.py`).

**실시간이 아닙니다.** 장중 데이터는 지연 시세 기준이므로 매매 타이밍 판단용으로는
적합하지 않습니다. 업종별 · 종목별 등락 쏠림을 한눈에 훑는 용도로 사용하십시오.
개장 직후 09:07 회차는 전일 종가에 가깝습니다.

---

## 5. 파일 구성

| 파일 | 용도 |
|---|---|
| `.github/workflows/update-map.yml` | 자동 갱신 · 배포 설정 |
| `fetch_yahoo.py` | 시세 수집 및 페이지 생성 |
| `verify_data.py` | 배포 전 데이터 이상 검사 |
| `korea_map_template.html` | 화면 템플릿 (색상 · 레이아웃) |
| `data.json` | 폴백 기준 데이터 |
| `sectors.csv` | 종목코드 → 종목명 · 섹터 (350종목) |
| `etf_universe.csv` | ETF 유니버스 (54종목) |
| `PROJECT_NOTES.md` | **운영 기준 문서 · 장애 대응표** |

`update_korea_map.py`, `requirements.txt`, 저장소의 `index.html` 및 `korea_map.html` 은
구 방식의 잔여 파일로 **현재 실행 경로에서 사용되지 않습니다.**

## 6. 수정하고 싶을 때

| 원하는 것 | 수정할 곳 |
|---|---|
| 섹터 분류 변경 | `sectors.csv` 의 섹터 열 |
| ETF 추가 · 삭제 | `etf_universe.csv` 에 행 추가 · 삭제 |
| 색상 · 레이아웃 변경 | `korea_map_template.html` 상단 `<style>` 블록 |
| 갱신 시각 변경 | `update-map.yml` 의 cron 값. UTC 기준이므로 **KST − 9시간** |

GitHub 웹에서 연필 아이콘으로 직접 수정하고 커밋하면 다음 갱신부터 반영됩니다.

**수정 전 반드시 `PROJECT_NOTES.md` 의 "바꾸면 안 되는 것" 항목을 확인하십시오.**
cron 분을 정각으로 바꾸거나 릴레이 방식을 되살리면 갱신이 불안정해집니다.

---

## 7. 문제가 생겼을 때

`PROJECT_NOTES.md` 의 **장애 대응표**를 보십시오.
증상별로 어디를 확인하고 무엇을 눌러야 하는지 정리해 두었습니다.

급하게 갱신이 필요하면
[Actions → Update KOREA MAP → Run workflow](https://github.com/bluelagoon1222/Finviz-Korea/actions/workflows/update-map.yml)
를 눌러 수동 실행하면 됩니다. 2~3분 후 반영됩니다.
